# Piano pensione

App personale per seguire il fondo pensione: TFR in busta paga, versamenti sul fondo, estratti conto, deducibilità e proiezione alla pensione.

Stato: prototipo funzionante in `prototype/index.html` (nato come artefatto claude.ai). Prossimo passo: PWA su GitHub Pages con dati su Neon. Tutti i dettagli per lo sviluppo sono in `CLAUDE.md`.
